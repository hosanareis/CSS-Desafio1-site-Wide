<p>Este projeto é uma página web desenvolvida com HTML e CSS como parte da minha prática em desenvolvimento Front-End.

A página apresenta uma interface de apresentação de serviço, com menu de navegação, imagem ilustrativa, título, descrição e botão de ação. O objetivo foi treinar a criação de layouts e aplicar estilos utilizando CSS.</p>
<br>

<h2>🚀 Tecnologias Utilizadas </h2>
<h3>- HTML5 <br> - CSS3</h3>
